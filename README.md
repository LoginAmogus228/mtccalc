# MTC Art Computer v3.0 PRO

Артиллерийский компьютер для плейса MTC в Roblox с автонаводкой и ИИ-анализом.

## 🎯 Возможности

### Автонаводка по координатам
- Ввод координат X, Y цели вручную
- Автоматический расчёт азимута и угла возвышения
- Мгновенное наведение орудия

### ИИ-модуль анализа
- **Определение типа снаряда** — ИИ анализирует цель и рекомендует оптимальный боеприпас:
  - ОФ-540 (осколочно-фугасный) — пехота, здания, лёгкая техника
  - Бр-540 (бронебойный) — тяжёлая броня на ближней дистанции
  - Кум-540 (кумулятивный) — тяжёлая броня на средней дистанции
  - Дым-540 (дымовой) — создание завесы
- **Анализ местности** — учёт городской/лесной/открытой местности
- **Оценка эффективности** — процент уверенности и эффективности
- **Автовыбор снаряда** — при включённой автонаводке ИИ сам выбирает снаряд

### Тактическая карта
- Интерактивная карта с сеткой координат
- Визуализация траектории полёта
- Круг рассеивания
- История попаданий
- Анимация выстрела

### Баллистика
- Расчёт азимута (0° = север)
- Угол возвышения по баллистической формуле
- Время полёта снаряда
- Учёт ветра (скорость + направление)

## 🖥️ Упаковка в .exe

### Способ 1: Electron (рекомендуется)

```bash
# Установка Electron
npm install --save-dev electron electron-builder

# Создание main.js для Electron
```

Создайте файл `electron/main.js`:
```javascript
const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
  const win = new BrowserWindow({
    width: 1400,
    height: 900,
    title: 'MTC Art Computer v3.0',
    icon: path.join(__dirname, 'icon.ico'),
    webPreferences: {
      nodeIntegration: false
    }
  });
  
  win.loadFile('dist/index.html');
}

app.whenReady().then(createWindow);
```

Добавьте в `package.json`:
```json
{
  "main": "electron/main.js",
  "scripts": {
    "electron": "electron .",
    "build-exe": "electron-builder"
  },
  "build": {
    "appId": "com.mtc.artcomputer",
    "win": {
      "target": "nsis",
      "icon": "icon.ico"
    }
  }
}
```

Запуск:
```bash
npm run build
npm run electron        # Запуск
npm run build-exe       # Сборка .exe
```

### Способ 2: Tauri (лёгкий .exe)

```bash
# Установка Tauri CLI
npm install --save-dev @tauri-apps/cli

# Инициализация
npx tauri init

# Сборка
npm run build
npx tauri build
```

Tauri создаст .exe размером ~5-10 МБ (vs ~150 МБ у Electron).

### Способ 3: Neutralinojs

```bash
npm install --save-dev @neutralinojs/neu
npx neu create mtc-art-computer
# Скопируйте dist/ в ресурсы
npx neu build
```

## 🎮 Использование

1. **Установите орудие** — перетащите зелёный маркер на карте
2. **Поставьте цель** — кликните по карте или введите координаты
3. **Настройте данные цели** — тип, броня, местность
4. **Включите ИИ** — получите рекомендацию по снаряду
5. **Включите автонаводку** — ИИ сам выберет оптимальный снаряд
6. **ОГОНЬ!** — нажмите кнопку выстрела

## ⌨️ Горячие клавиши (при использовании в Electron)

- `F1` — включить/выключить ИИ
- `F2` — включить/выключить автонаводку
- `Space` — выстрел
- `R` — сброс цели
- `T` — показать/скрыть траекторию

## 📐 Баллистическая модель

- Гравитация: 196.2 studs/s² (Roblox)
- Начальная скорость зависит от типа снаряда
- Угол возвышения: θ = 0.5 × arcsin(g×d/v²)
- Максимальная дальность: v²/g

## 🔧 Настройка

В коде можно изменить:
- `GRAVITY` — гравитация
- `MAP_SIZE` — размер карты
- `SHELL_TYPES` — характеристики снарядов
- `windSpeed/windDirection` — параметры ветра
